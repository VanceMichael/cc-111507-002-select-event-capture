# 运单对象查询来源格式

响应 Content-Type=application/vnd.amazon.eventstream，帧由大端 totalLength、headersLength、prelude CRC32、类型化头、payload、message CRC32 构成，长度包含两个 CRC。头支持 string(7)。事件包含 Records、Progress、Stats、End；message-type=error 带 error-code/error-message。Records 为 UTF-8 RFC4180 CSV 字节流，首行为列名，可含引号和内嵌换行；Progress/Stats 是 XML。完整收件只在合法 End 后成立。每条记录暴露 id、note 和来源帧区间，统计单独放 coverage。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://docs.aws.amazon.com/AmazonS3/latest/API/RESTSelectObjectAppendix.html。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
